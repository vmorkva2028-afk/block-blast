# Block Blast

Клон игры **Block Blast** на Python + Kivy. Работает на Android.

## Что это

Головоломка, где нужно расставлять фигуры на сетке 8×8. Когда строка или столбец заполняется — она исчезает, и ты получаешь очки. Игра заканчивается, когда ни одна из трёх фигур не помещается на поле.

## Как играть

- **Перетащи** фигуру из лотка внизу на поле.
- **Тапни** по фигуре в лотке — она повернётся.
- **Заполни** строку или столбец — они исчезнут, ты получишь очки:
  - 1 линия = 10 очков
  - 2 линии сразу = 30 очков
  - 3+ линии = 60 очков
- **Рекорд** сохраняется автоматически.

## Особенности

- 🎨 Псевдо-3D визуал клеток
- ✨ Анимация исчезновения линий
- 💥 Тряска экрана при комбо
- 🏆 Сохранение рекорда

## Технологии

- **Python 3.11**
- **Kivy 2.x** — кроссплатформенный UI-фреймворк
- **Buildozer** — сборка APK
- **GitHub Actions** — автоматическая сборка

## Как собрать APK

1. Форкни репозиторий.
2. Зайди во вкладку **Actions**.
3. Дождись завершения сборки.
4. Скачай APK из раздела **Artifacts**.
